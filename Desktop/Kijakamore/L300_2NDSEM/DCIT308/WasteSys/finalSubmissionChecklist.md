# Final Submission Checklist

Use this checklist before submitting WasteSys.

## Report files

- Export `totalReport.md` to PDF.
- Export `totalReport.md` to DOCX if required.
- Make sure the PDF/DOCX includes the trace tables, proof sketches, dataset description, database schema, and performance notes.

## Evidence files

- Include screenshots of the console menu.
- Include screenshots of loading seed data.
- Include screenshots of the database summary.
- Include screenshots of the team-parameter summary.
- Include screenshots of the efficiency lab output.
- Include `results/efficiency-search-sort.csv`.

## Code and database files

- Include the source code folder or a ZIP export of the repository.
- Include `schema.sql`.
- Include the seed CSV files under `src/main/resources/data`.
- Include the SQLite database file only if your instructor requests it.

## Team requirements

- Replace the sample team index numbers with the real 13 student index numbers.
- Confirm the runtime app still works with `scripts/run-app.ps1`.
- Confirm the smoke tests still pass with `scripts/run-tests.ps1`.

## Final package

- Final report PDF
- Final report DOCX if required
- Source code ZIP or Git export
- `schema.sql`
- CSV seed data files
- Efficiency CSV results
- Screenshots
- Database backup if required
